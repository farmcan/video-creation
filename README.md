## 维护与发布

需要 Python 3，无第三方构建依赖。

```sh
python3 scripts/build.py
python3 scripts/export.py --target ../farmcan-websites
```

只在 main 维护。先提交并推送本仓库，再导出；本仓库的源版本和三份静态文件哈希写入 build-manifest.json。导出后在既有 farmcan-websites 仓库构建、检查、commit/push，复用 Actions 发布与 release.json / 首页哈希验收，并额外核验 creation 页的字节。

- `projects/`：结构化状态、路线、验收标准、选题与参考链接。
- `research/`：原创研究与操作笔记。
- `site/`：静态界面模板与原创图标。
- `dist/`：不提交的生成页面，只显式导出选定文件。
