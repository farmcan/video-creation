# 视频图片清晰度返修

1. **先看出片，再看原图。** 在最终尺寸和手机预览抽帧。记清是原图失焦、运动模糊、压缩、裁切错误，还是只是画面没铺满。注明在几秒影响看清脸、手、道具或梗内文字。
2. **找同帧，再找同场相邻帧。** 优先官方原视频、发布会图、社区原帖和干净母版；对照姿势、服装、道具及画面内文字。低清原帧即使被放大也未必有更多细节；相邻帧要能继续讲同一个包袱。找到的换图先看成片中的效果，不能只比较像素数。新闻或史实镜头优先用真实出处，不用生图补出不确定的画面细节。
3. **确实缺失时再参考重制。** 提示词明确列出要锁定的景别、人物、表情、动作、手指、道具、光线和梗的文字；只修指定模糊或叠印，不添加新情境。按原件对照检查。重制稿记录为衍生素材，不能当作新的事实证据。额外梗图和封面先给用户看、按确认范围替换。
4. **分开画面和字幕。** 清晰版原图无硬字幕时，撤掉旧的避字幕裁切；接近 16:9 时用等比放大和少量裁边撑满，绝不拉伸。截取前后都看脸、手和道具；正式字幕继续走统一轨道，英文在上，中文在下。
5. **留全套证据。** 本地保留旧版、原始候选、选中源、参考重制、缩略图和最终使用版本。仓库提交来源链接、像素、相对路径、SHA-256、替换理由与镜头号，原始媒体不入 Git。独立查看实际导出，记录检查位置，以及需要继续保留的缺口。
