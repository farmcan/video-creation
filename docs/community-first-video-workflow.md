# 先看社区作品，再做视频

适用于新选题、人物更换与实质改创意；小幅修字、调时沿用已核参考，不重做整轮研究。目标是先做出观众能看懂、有具体笑点的短开头，再扩全曲。与[按曲创作流程](creative-song-workflow.md)共同使用。

1. **读旧成果与反馈。** 先找本项目的参考研究、创作立意和最近否决原因，区分旧方案、当前方案与待验。写一句目标观众、他们已经知道什么，以及这段想让他们发现什么。
2. **实看 2–3 个同类作品。** 优先原作者／原帖，实际看图片或视频，记人物、动作、铺垫、反转、反应镜头与停留时间。只看到截图就只分析截图；来源失效保留缺口，不靠标题补剧情。
3. **提取机制并接到内容。** 每个候选写「歌词／叙事功能 → 观众预期 → 哪一画面改变预期 → 后面如何回扣」。记录平台、观察日期、原帖与带单位的传播指标；播放、点赞、票数和独立用户不能混用。热度是选参考的线索，趣味仍要看实际表达。
4. **选现成情境，再补缺口。** 优先观众认识的表演、反应和社区模板。需要生成时，先说明它补哪个不可替代的动作；生成标签只说明媒介，不能证明笑点成立。梗中被贴上名字的脸不自动等于真实本人，虚构同框不能当新闻证据。第三方媒体留在仓库外，来源文字与原创分析入库。
5. **先剪短开头。** 从人物／处境进入，落第一个包袱，给观众读懂的时间；同步检查音轨、完整乐句字幕和切点。先看效果，再增加镜头数量与后续副歌变化，避免把全曲素材准备当作全曲制作完成。
6. **独立看片并迭代。** 让未参与制作的 Agent 看实际导出媒体，回答：不读制作说明能否认出人物与冲突；包袱在哪、是否成立；是否只有贴题却无反转；字幕与歌声是否同步。每条意见附时间点和改法，返工后复看。未能读取声音或完整视频必须说明，不能宣称该项通过；用户最终反馈继续作为验收依据。

每轮只留简短交接：参考及实看范围、采用的机制、样片路径／版本、评审问题与时间点、用户反馈、下一步。失败方案标停用并保留理由，避免后续 Agent 换个提示词重复同一问题。

## 本轮剪映实测补充

- 预合成预览的换行不代表剪映 SRT 导入结果。原生最小字号本轮为 5，英文会按字符折行，可能把 don't 或 man's 拆开；原生专用稿按完整单词显式换行（本次每行不超过 44 字符、最多两行），再查看真正导出文件的长句和重复副歌。字号与字符上限是本轮画幅／字体实测，不是跨设备固定标准。
- 隐藏旧字幕轨后再加同时间、部分同文本的修稿，本轮只新增了变更片段；不能看到一条新轨就认定 44 句齐全。保留旧工程与源 SRT 后，撤去重复底版、完整重导，检查首句、尾句和各副歌，再保存重开。
- 时间线纵向滚动可能把字幕轨移出可视区；先回放句中并向上滚动，不凭看不到轨道就误报保存丢失。吸附可能把点击定位吸到字幕结束边界；检查句中应先关闭吸附或确认实际时间码。
- 审核两版差异：v5 的主预览和原生导出均英文在上、中文在下，片头无唱词时也为剧情和标题加双语。主预览加频谱，原生工程使用可编辑字幕。分别记录实际看片范围。
- 封面先给观众看形成反差的双方：这次是 DeepSeek / Kimi 对 Alice Huang（黄乐）。保留标题和辨识人物所需文字，删掉额外的引导问句、注释和梗的解释；先在缩略图尺寸核对双方是否一眼可认。

- 清理素材时先对照源图和出片，区分叠加水印、画面自带字幕与梗内文字。优先找同画面干净版；需参考重制时逐处描述水印并锁定表情、动作与构图。源作者和重建说明记交接文档，替换后抽看实际导出。见[本次素材清理](../projects/jensen-song-2026-11-17/ASSET-CLEANUP-v6.md)。
