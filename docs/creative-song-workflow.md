## 每次换题先填写

```text
题材／人物：
受众与语言：
叙述者是谁：
支持／讽刺的具体对象：
一句话立意与听众应记住的动作：
曲名、版本、时长、源文件或来源索引：
交付范围（全曲／短片）与可验证核心动作：
事实截止日期与一手来源：
事实／观点／角色猜测／虚构分别是什么：
预算、已有账号与可用操作边界：
```

叙述者和讽刺对象先定清。例如，标杆由获利者若无其事地庆祝，新题材若要支持中心人物，就应重新选择朋友或旁观者等讲述位置；直接替换人名可能把支持对象写成被讽刺者。

## 最小执行顺序

1. **锁版本和完整范围。** 对照本地源与来源信息，确认速度、段落、重复、副歌与尾奏。不同版本的时间戳不能直接互换，8 秒参考不能证明全曲旋律已受约束。全曲任务仍交完整词稿，短段只验证最难乐句。
2. **读一个相关标杆，提炼机制。** 记录叙述者、情绪与事实的反差、具体场景、铺垫、包袱、升级与回扣。OCR／字幕用于定位；同屏下一句、背景文字与演唱字幕要分开。没有声音或谱的地方保留 unknown。
3. **做全曲乐句表。** 给所有乐句稳定 ID，包括呼应、三遍副歌、间奏。先用字数／字幕作初稿代理，再核真实音节、弱起、强重音、停顿与拖音；不要套固定行数或每行音节模板。
4. **先分配意思和梗。** 每句承担交代、铺垫、包袱、升级或回扣中的一个主要任务。主歌给新场景，副歌固定核心姿态；第二主歌增加信息，最终副歌回应前文。事实来源和猜测标签随句保留。
5. **逐句写少量候选，再通唱。** 保留意图与包袱，调整词序、密度和句式。先用自然口语与可见动作，行业术语后立刻接后果；双关须听得清，不能靠中文注释补救。韵脚按发音选，专名和缩写单列风险。
6. **分开保存三份文本。** 阅读／字幕稿正常拼写；分句表记约束、发音和改写原因；生成输入稿只放唱词和少量结构提示，Style 另存。重复副歌明确展开，不用省略号代替。
7. **先验证，后扩大生成。** 核对实际参考、模型、输入残留、权限、预算与可见参数；固定一份基准，每次只改能解释的一项。按钮转圈不算获得任务；终态未知时不重复提交。同类失败重复出现先停盲抽，区分参考、文本、能力、权限和播放链路。
8. **验声音后交接。** 取得可播放完整音轨，再逐句比目标原曲。局部有误优先定位失败 ID 与可用修补入口，修补后通听接缝及全曲。录音、ASR 与诊断材料留私有目录；只提交原创文字、脱敏结果和必要来源。

## 验收不能合并成一个“成功”

| 项目 | 足以推进的证据 | 仍不能据此宣称 |
| --- | --- | --- |
| 内容与梗 | 完整叙事、明确立场、事实标签；口语可理解，铺垫与回扣成立 | 已合原旋律、实际演唱有趣。 |
| 字词约束 | 词典与分句检查覆盖所有句；专名读法明确 | 音节总数相同便重音、停顿、拖音正确。 |
| 播放与完整性 | 可听文件、首尾与中间检查，覆盖全部段落 | 仅播放器计时或无长静音便全曲听感合格。 |
| 实际唱词 | 无提示 ASR 提供定位线索，再回听核实漏词／旧词／发音 | ASR 文本即真实演唱，或词对即曲对。 |
| 旋律与节奏 | 原曲和输出逐乐句对照，主歌、各遍副歌与尾部均覆盖 | 只听开头、副歌相似或伴奏对齐便全曲旋律一致。 |
| 最终听感 | 整曲通听，重音、换气、包袱落点、接缝分别记录 | 文字漂亮或音质好便目标完成。 |
