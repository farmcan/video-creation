# 社区二创：梗、标题和投稿包装

目标是让对的人愿意点开，并且进来几秒就看见承诺的东西。热度是选题线索，标题、封面和内容是否匹配才是可控项。

1. **先核热点。** 查平台站内原帖、2–3 条同梗变体和实际评论；记录平台、URL、发布时间、观察日、可读的互动量及其口径。明确是近期热议、长期通用梗，还是仅看到了历史快照。不能看原媒体的只分析可见标题／正文，不能声称看过片头。用真实梗的机制，不搬原封面或复制标题。
2. **拆成三个不同的信息。** 标题先放可认的人、原曲或可搜事件，再承诺形式或反差；封面只给一个清楚的画面矛盾；开头尽快让观众看到预期和反转。手机缩略图认不出主角、正文开头看不懂、点击预期与片头不符，先修再发。没必要把同一句梗印三遍，或用“到底是哪种”等解释口吻把答案写出来。
3. **按平台写一个主稿。** B 站完整 MV：人物／曲名／改词形式容易被搜到，简介首两行交代独特内容，末尾记制作和来源。抖音：一句可读的钩子，短版先有反差再进歌，话题只选真的相关的。X：用目标语境写一句能单独成立的梗，再加一句作品是什么；明确 parody，不把合成人物当成本人发言。提取对应短版后检查裁切和字幕，不把写好文案误称短视频已经制作。
4. **只验证一个变化。** 有账号曝光时，曝光不足先看题材和时段；曝光有但点击弱，检视标题／封面；点击可以但头几秒掉，检视承诺、起音和兑现速度；后段骤降可能是节奏问题。1h／24h／72h 到点记录可见的曝光、CTR、开头留存、完播、分享；平台不给的标缺口。比较两个相近作品或用官方 A/B；手动改标题后的两段数据不等于随机实验，不承诺推流。时间核对见[发布时间研究](../research/publishing-time-video-2026-11-19.md)。

可复用来源：[YouTube 官方标题与缩略图指南](https://support.google.com/youtube/answer/12340300)的准确、简短、关键词前置，以及[官方 A/B 方法](https://support.google.com/youtube/answer/16391400)的同一作品对比；后者不是其他平台的功能或算法。GitHub [yt-dlp](https://github.com/yt-dlp/yt-dlp#usage-and-options)的 `--skip-download --dump-single-json` 可在允许访问的链接采集元数据，失败时保留缺口；[youtube-agent-skill](https://github.com/utillayer/youtube-agent-skill)的题图互补、片头过问和留存诊断可当人工检查项。未安装或引入其代码，规则分数不是流量模型。

涉及合成画面时，发布前核实来源与可用范围，按 [B 站](https://www.bilibili.com/opus/1106496554576904197)、[抖音](https://trust.douyin.com/article/15868)、[X](https://help.x.com/en/rules-and-policies/authenticity)当前要求声明。常规创作注释留简介／交接；平台要求的声明照做。未获得发布授权、不合适的素材许可或未核实的新事实，保持待发布。
