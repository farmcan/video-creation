# 给老黄留个座 · v5 转剪包

1280 × 720，30 fps，3:47.600，时间线从零开始。

1. 解压整个文件夹。在 DaVinci Resolve 或 Premiere Pro 导入 `timeline.xml`（Final Cut Pro 7 XML），得到原切点处的 60 个画面片段和独立 WAV。换电脑或移目录，若显示媒体脱机，按文件名把媒体重新链接到包内 `media/`，无需重新摆放。
2. 单独导入 `subtitles-en-zh.srt`，对齐时间线起点 `00:00:00:00`。48 条字幕，包括无演唱片头三条、44 条歌词和片尾一句，英文在上、中文在下。字体、描边等样式按目标软件调整。
3. `source-images/` 有实际用到的 16 张图片，可重新构图；`shots.json` 保存图名、裁切和精确切点。已裁好构图的片段在 `media/shots/`；这些片段不含文字或声音。`preview.mp4` 供对照，不用叠进新时间线。`cover.jpg` 是单独选用的封面。

本包从已抽查的 v5 画面、音轨和字幕重建，未序列化剪映的内部工程。XML/SRT 的媒体链接和时码已本地核验；本机未实际打开 Resolve / Premiere。仅作本地转剪与核对，原图不随 Git 和公开进度页发布。
