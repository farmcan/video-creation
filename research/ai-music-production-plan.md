# AI 填词音乐首条视频实验：30 秒操作方案

## 实验问题与固定条件

问题：已有新词和目标旋律时，哪条工具链最容易得到词清楚、旋律准确、节奏自然的歌声？先固定《朋友的酒》原旋律及参考 B 站视频的英语填词做私有对照。本页不转载歌词，测试中不改词，不用新热点干扰技术比较。

选约 30 秒、起止均为完整乐句的副歌。记录实际起止点、拍速、调性、每句入口、换气、重音和句末拖音；未知项先标待测。不要只截半句。给三个候选使用相同歌词、相同目标片段，导出可听文件并记录实际工具版本、输入、参数和失败原因。

参考标杆为 [梨茗子英语填词《朋友的酒》](https://www.bilibili.com/video/BV1Este6wExx/)。具体工具没有确认；本实验比较输出效果，不声称还原作者的方法。

## 第一步：准备可比较的输入

1. 核对参考版本、准确片段和新词。新词如来自自动识别，逐句听辨，未确认的词保留疑问，不让模型补造。
2. 将每句拆成英文音节，标注强拍、弱读、拖音和停顿。单词数量不等于音节数，押韵也不等于唱得进拍。
3. 准备参考音轨与伴奏。需要分离时可用 Ultimate Vocal Remover；试听有无旧人声残留、鼓镲污染和低频损伤。分离失败不等于生成失败。
4. 保留一份未处理的对照片段，另存工作副本；测试音轨只留私有。公网研究页不附原媒体、完整歌词或生成结果。

## 第二步：先测 A，再决定 B 或 C

### A · 参考音频直接 Cover

- 核对当前账号的上传、Cover / Remix 和歌词编辑入口，确认实际可用功能后才执行。
- 放入目标片段和新词；第一轮尽量保留原有曲风，不同时改变语言、速度、编曲和歌手表现。
- 先比较少量候选，标记每句是否混回旧词、改旋律、漏词或抢拍；不要只挑音质最漂亮的一版。
- 同一错误连续出现时停止重复抽取，转到 B 或 C。默认没有必要先做整首。

官方当前页面主要描述保留已有歌词；2024 年历史说明允许尝试改词。两者都不承诺本实验会成功。网页按钮和账户功能的存在也不算声音验收通过。

### B · 新词导唱再 Cover

- 按原旋律录一条清晰导唱，优先保证节奏、词与音高；允许声音粗糙。
- 听辨导唱本身是否唱对，确认后再把它作为参考，尝试增强声音与编曲。
- 若导唱含跑调、错误重音或漏字，先修导唱；不把上游错误算成工具生成能力。
- 如果成品把正确导唱重新改坏，保留失败片段，转 C 做逐音修正。

这是待验证方案；没有“导唱一遍必然成功”的证据。也不要求复刻参考歌手的音色，本轮核心是词曲与节奏。

### C · MIDI / 音符编辑合成

- 采用准确旋律谱，或从分离后人声提取 MIDI；校正自动识别中的和声、颤音、滑音与跨拍错误。
- 在 Synthesizer V 逐音输入新词，按音节拆分，处理一音多字、一字多音、弱读和尾辅音。
- 先在干声里检查词与拍，再加入表现参数；最后导出人声混回伴奏。
- 混音时对齐入口、响度与空间感。不要用大混响掩盖不准的落字，保留干声供复核。

官方支持音符、歌词与 MIDI 编辑；不保证自动提取正确，也不保证未调校输出达到标杆。拿到实际音轨后才能评价自然度。

## 第三步：听什么才算接近

以下是本实验自定的验收标准，不是行业统一标准。听者在同响度下比较标杆与候选，能匿名试听时隐藏工具名称，减少品牌影响。

| 检查项 | 通过条件 | 常见失败 |
|---|---|---|
| 词完整 | 所选片段每句均唱到目标词，听者可辨认；无旧词混入。 | 漏词、硬凑词、回到原词。 |
| 旋律 | 所有完整乐句的核心音高走向和句末收束均保持。 | 另写一条旋律，或只保留伴奏。 |
| 节奏与落字 | 句首、重音、停顿与拖音在目标位置，听起来不挤拍。 | 多音节硬塞，尾辅音被切断。 |
| 自然度 | 吐字清楚，无明显机械断裂、错误英语重音或合成破音。 | 词正确但唱法生硬。 |
| 伴奏与混音 | 人声清晰、入口同步，无显著旧声残留、削波或过量混响。 | 分离伪影掩盖生成质量。 |

前两项任何一句明显失败，都不称为“技术接近”。若词曲通过而自然度差，记录为局部通过，继续调校，不用单个总分掩盖问题。可辅以音高轨迹和拍点测量，但测量不能代替试听，颤音与滑音也可能误导自动指标。

## 通过后如何变成首条视频

选一条原创主题，用同样的音节—重音—韵脚方法写 30–60 秒原创词；先让非创作者听懂故事，再检查押韵。音轨通过后制作准确字幕、简明画面与前几秒的情境钩子。先用能完成表达的画面，不预设必须做复杂 AI MV。

记录真实反馈：听者能否复述主题、哪句愿意重听或分享、哪里看不懂或出戏。技术复现只解决制作能力，不能证明标题、选题、付费意愿或流量。公开发布前另行核对素材权利、署名和平台要求；本实验不代替发布审查。

## 生成条目出现后：先修输入，再验短句

当前操作确实是 Cover，不能把不满意的输出笼统解释成“用了错误模式”。Simple / Advanced 是表单，v6-mini / v6 / v6-wild 是模型，Cover 等是操作，country rock / roots rock / Americana 是目标风格。

优先检查继承输入：继续用原始源片段，不把偏离目标的生成曲当作新参考；清除中文 Lyrics，只输入目标英语词；把 Mandopop、合成器与鼓机方向改成乡村摇滚的木吉他、电吉他、贝斯和现场鼓组。8 秒参考只能约束短句，不能指定两分钟新增段落的全部旋律。先试听现有条目，并在完整短乐句上核对歌词、旋律、重音和风格，再扩大整首。上述是待验证的改进方案，不是已确认根因或成功配方。
